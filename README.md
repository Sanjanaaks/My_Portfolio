## 🛠 Features & Highlights

- **Typewriter effect** in the header for your value proposition  
- **Animated project metrics** (counting up) to emphasize results  
- **Scroll-triggered animations** (fade-in, staggered cards)  
- **Interactive certifications**: click to expand details  
- **Parallax background sections** for visual depth  
- **Sticky navigation bar** with smooth scrolling and active link highlighting  
- **Floating resume download button** reachable from any section  
- **Responsive design** across devices  
- **Hover & transition effects** on icons, buttons, cards  
- **GitHub & LinkedIn links** integrated for easy access  
- **Resume download in footer & floating button**
